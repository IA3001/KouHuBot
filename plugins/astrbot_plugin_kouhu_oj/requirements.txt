# 本插件的额外第三方依赖。
#
# AstrBot 基底镜像里已经带了 Pillow，这里只声明它没有的两个：
#
#   curl_cffi  —— 绕过 Codeforces 的 Cloudflare 挑战。
#                  CF 的题面页在「Just a moment...」JS 挑战后面，且挑战难度取决于
#                  客户端的 TLS 指纹。cloudscraper 在开发机上能过，但在部署容器里
#                  一律 403（容器 OpenSSL 3.5 的握手比开发机 3.0 更像脚本）。
#                  curl_cffi 用 BoringSSL 完整复刻 Chrome 的 TLS 指纹，容器里稳定 200。
#                  实测单题 0.6~0.9 秒。
#
#   matplotlib —— 用 mathtext 把 $$$...$$$ 里的 LaTeX 画成小图，嵌进题面。
#                  完整 LaTeX 发行版要上百 MB，2C2G 的机器放不下；mathtext 是
#                  matplotlib 自带的子集，对 CF 题面覆盖率达到 100%（前提是先把
#                  CF 的非标准宏 \le \ge \lt \gt 归一化掉）。不归一化只有 91%。
#                  代价：装完 27MB，导入 0.4 秒，常驻内存 +47MB。
#                  容器内存上限 900M，实测出图后总占用 81MB，完全够用。
curl_cffi>=0.7
matplotlib>=3.7,<4
