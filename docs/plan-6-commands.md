# 计划 6：指令规范

> 状态：待确认 `giveup` 语义
> 原则：**全部使用完整英文单词，不使用单字符缩写**

## 玩家指令

| 指令 | 作用 | 权限 |
|---|---|---|
| `new` | 派下一道题 | 任何人；当前题必须已 AC 或已关闭 |
| `submit <思路>` | 提交作答 | 已报名 |
| `giveup` | 放弃当前题 | 已报名 |
| `problem` | 重看当前题（重发图片） | 任何人 |
| `rank` | 积分榜 | 任何人 |
| `me` | 我的战绩 | 任何人 |
| `join` | 报名参赛 | 任何人 |
| `help` | 帮助 | 任何人 |
| `grammar` | C++ 坑点练习（保留） | 任何人 |
| `ask <问题>` | 自由问答（保留） | 任何人 |

## 管理员指令

| 指令 | 作用 |
|---|---|
| `skip` | 强制关闭当前题 |
| `tier <数字>` | 手动设群难度档，覆盖自动升降 |
| `status` | 运维信息 |

## 废弃的旧指令

单字符与其他缩写全部移除：

```
q  n  s  g  r  p  h  grm
submit 之外的旧别名一律不再接受
```

保留 `submit` / `giveup` / `rank` / `problem` / `help` / `grammar` / `ask` 正是它们原本的全名。

## `giveup` 的语义：全群作废（已定）

**任何人发 `giveup`，当前题立即关闭，允许 `new`。**

已知风险并接受：一个人可以顶掉全群正在做的题。
缓解手段：`players.gave_up` 记录每人放弃次数，`rank` 里可见；
管理员 `skip` 是官方版本的跳过，`tier` 可手动纠正难度。

放弃不计分、不扣分。
