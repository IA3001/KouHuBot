# 计划 2：题目拉取

> 状态：技术链路已验证，待开工
> 依赖：计划 1（CF Rating 竞技榜）

## 目标

从 Codeforces 拿到真实题面，翻成中文，渲染成图片发到群里。

## 实测结论

### 题面抓取：cloudscraper 可行

| 路径 | 结果 |
|---|---|
| CF 官方页（普通 HTTP） | ❌ 403，Cloudflare JS 挑战 |
| CF 官方页（用户服务器） | ❌ 403（已实测） |
| r.jina.ai / allorigins / corsproxy / codetabs / thingproxy | ❌ 403 / 522 / SSL 断开 |
| Wayback Machine | ❌ 429 限流 |
| 洛谷 `_contentOnly` | ❌ 已下线，返回 SPA 空壳 |
| 洛谷 `og:description` | ⚠️ 只有前 120~160 字 |
| **cloudscraper** | ✅ **200，4/4 成功，0.5~0.9 秒/题** |

CF 的 `robots.txt` 明确 `Allow: /`，只禁 AI 训练爬虫（`ai-train=no`）。
**爬取不违反 CF 的规则**，拦住的是 Cloudflare 的机器人防护。

### 公式渲染：matplotlib mathtext 可行

CF 用 `$$$...$$$` 包 LaTeX。

```
原始 mathtext 覆盖率   131/144  (91%)
加宏归一化后           144/144  (100%)   0.6 秒渲染 144 个公式
```

失败原因是 CF 用了非标准 LaTeX 别名，映射即可：

```python
'\\le'   → '\\leq'      '\\ge'   → '\\geq'
'\\lt'   → '<'          '\\gt'   → '>'
'\\dots' → '\\ldots'    '\\text' → '\\mathrm'
```

成本：matplotlib 包 27MB，import 0.4s，RSS +47MB，渲染约 4~7ms/公式。

### 翻译：保护公式 + 判题喂中英

- 翻译前把 `$$$...$$$` 换成占位符，翻完填回，防止 LLM 破坏公式
- 题面只发中文（图不炸）
- **判题 prompt 同时给英文原文和中文译文**，让模型自己对齐，减少错译导致误判

## 完整链路

```
cloudscraper 抓 CF 题面 HTML
  → 提取 <div class="problem-statement">
  → 抽 $$$...$$$ 公式，替换成占位符
  → LLM 翻译正文
  → 填回公式，宏归一化
  → matplotlib 渲染每个公式成小图
  → Pillow 拼版（正文 + 公式图 + 样例块）
  → 发图
```

## 已知风险

| 风险 | 缓解 |
|---|---|
| cloudscraper 靠模拟浏览器指纹过 Cloudflare，CF 改防护就失效 | **爬过的题永久落库**，挂了也不影响已有题库 |
| 并发抽题同时打 CF，可能触发封 IP | 全局信号量 + 队列，限制并发 |
| 翻译术语错误（subsegment / query / permutation） | 判题同时喂中英原文 |
| 题号暴露 → 玩家直接搜 editorial | **未解决**，见下 |
| 题面比 LeetCode 长，图片会很高 | 需实测排版 |

## 未解决：题号暴露 = 搜题解

`q` 一旦发出，玩家就知道是 CF 哪道题。CF 每题都有官方 editorial、
大量博客题解、GitHub AC 代码。**零门槛、五秒钟就能抄到。**

这不是小概率作弊，是理性玩家的最优策略。rating 榜可能退化成「谁最会搜」。

候选缓解（都未定）：
- 隐藏题号，只发题面和 rating（玩家仍可通过题面搜到）
- 抽题后限时作答，压缩搜索窗口
- 接受它，靠群内自觉

---

## 最终决定（已确认）

| 项 | 决定 |
|---|---|
| 题面抓取 | cloudscraper，慢速（≥2s 间隔），爬过永久落库 |
| 公式渲染 | matplotlib mathtext + 宏归一化（实测 100%） |
| 翻译 | 占位符保护 `$$$...$$$`，只发中文译文 |
| 判题输入 | **同时喂英文原文 + 中文译文**，减少错译误判 |
| 题号 | **做题时不发，AC 后揭晓**（防搜题解 + 开盲盒爽感） |
| 排版 | **分两张图**：① 题面正文 ② 样例 + 提示 |

### 题面长度实测

| 题号 | rating | 英文字数 | 公式数 |
|---|---|---|---|
| CF2276E | 1800 | 1212 | 33 |
| CF2276D | 1400 | 1509 | 22 |
| CF2271C | 1400 | 2324 | 63 |
| CF2268A | 1200 | 1665 | 35 |

平均 1627 英文字符 → 中文约 2600 字，22~63 个公式。
单张 900px 宽渲染约 2900px 高，手机要滑 3~4 屏，故分两张。

### 防搜题解的效果边界

只发中文译文、不发题号时，玩家只能拿**你模型翻的中文**去搜，
和洛谷译文、CF 原文都不匹配，搜索基本失效。

但**经典题会被认出来**（两数之和、单调栈模板题等）。这是无法消除的。
