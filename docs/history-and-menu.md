# 0.12.0 菜单与历史入口

help 使用分类标题、统一 emoji、分隔线和单行指令。QQ 的比例字体和 emoji 宽度不同，不依赖连续空格构造表格。分区为正题、坑点、历史与复盘、积分规则、反馈复核、帮助更新、管理员。

history [页码] 按题汇总个人历史，history grm [页码] 为坑点。列表显示题号、记录数、各类判定、累计已知得分与提示记录；旧版未知数据不补造。进行中隐藏题号。

history problem 628B 重发历史正题题面和样例；不会更新当前题、轮次、出题记忆、积分、提交状态。sub 始终提交当前正在进行的题。历史缓存缺失时直接提示，不切换题目。坑点用 history grm problem 稳定ID；已隔离坑点不从候选区恢复内容。

history show 628B [页码] 每页回看3次自己的作答和判词，显示原提交编号用于 appeal。旧 history show 数字入口暂兼容。sol 628B 按题号定位本群自己最近的该题记录并获取轮次解析；sol 不带参数查当前已结束正题。CF628B 形式同样接受；纯数字参数不再表示提交编号，返回迁移提示。同题多次提交共用该轮解析是预期行为。

同题正在重开时，历史作答与解析暂时禁止；题面可只读回看。个人/群/正题与坑点隔离继续有效。复核仍按一次提交，不能把申诉号改成题号。

验证：50项工具/存储/渲染测试、181项单元检查、278项模拟群聊检查。新增验证同题WA/AC分组合并、历史题面+样例同时发送、槽位不变、按题作答和旧sol用法提示，以及菜单各分类入口。
