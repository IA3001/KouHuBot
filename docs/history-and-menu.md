# 0.12.0 菜单与历史入口

help 使用分类标题、统一 emoji、分隔线和单行指令。QQ 的比例字体和 emoji 宽度不同，不依赖连续空格构造表格。分区为正题、坑点、历史与复盘、积分规则、反馈复核、帮助更新、管理员。

history [页码] 按题汇总个人历史，history grm [页码] 为坑点。列表显示题号、记录数、各类判定、累计已知得分与提示记录；旧版未知数据不补造。进行中隐藏题号。

history problem 628B 重发历史正题题面和样例；不会更新当前题、轮次、出题记忆、积分、提交状态。sub 始终提交当前正在进行的题。历史缓存缺失时直接提示，不切换题目。坑点用 history grm problem 稳定ID；已隔离坑点不从候选区恢复内容。

history show 628B [页码] 每页回看3次自己的作答和判词，显示原提交编号用于 appeal。旧 history show 数字入口暂兼容。sol 628B 按题号定位本群自己最近的该题记录并获取轮次解析；sol 不带参数查当前已结束正题。CF628B 形式同样接受；纯数字参数不再表示提交编号，返回迁移提示。同题多次提交共用该轮解析是预期行为。

同题正在重开时，历史作答与解析暂时禁止；题面可只读回看。个人/群/正题与坑点隔离继续有效。复核仍按一次提交，不能把申诉号改成题号。

验证：50项工具/存储/渲染测试、181项单元检查、278项模拟群聊检查。新增验证同题WA/AC分组合并、历史题面+样例同时发送、槽位不变、按题作答和旧sol用法提示，以及菜单各分类入口。

## 0.22.0：这些入口改成图片卡片

history 的三种形态（按题汇总、每次作答、提交详情）、mistakes、me、sol 现在都发一张卡片图，字段与文字版一一对应（题号/记录数/判定轨迹/累计得分/提示口径、错题的未过次数与距今、战绩五项指标、解析来源与原文链接）。进行中的题照旧显示「进行中（结束后揭晓）」，隐藏口径没有因为改形态而放松。

图里的命令点不动，所以每张卡的页脚用等宽胶囊把可用的命令写出来，sol 的图后面还会补一条可点的官方原文地址。提交详情一次装下整条记录，不再按 1400 字切页；超长作答才切成多张并标注「作答 i/n」。

图片不受消息长度限制，所以每页条数按「一张图装完」定：history 30 题、按题作答 20 次、错题本 20 题（文字回退保持 5 / 3 / 5）。30 题的列表卡约 900×4.6k px，字仍是同一号字。

渲染失败或 `record_cards_enabled=false` 时，行为与 0.21.x 的文字版完全一致；`sub` / `giveup` / `grm giveup` 的即时回执保持文字。验证：346 项模拟群聊检查（含 19b 记录卡片一节）与 615 项单元检查。

me 是 CF 风格的个人主页（0.23.0 起）：rating 取已 AC 题目的平均档位（每 50 分一档，少于 3 道显示未定级），
另有今日/本周/本月做题数与得分、26 周做题热力图、每日累计积分曲线、最近做过的题。
口径集中在 profile.py，卡片只排版；文字回退仍带今日/本周/本月一行。
