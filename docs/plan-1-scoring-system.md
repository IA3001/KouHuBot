# 计划 1：加权积分榜

> 状态：规格已锁定，待开工
> 取代：ELO Rating 方案（已废弃，原因见文末）

## 核心机制

```
不做 rating。只算过题数 × 难度权重。

题目按 CF rating 分档，每档预先定一个分值
玩家总分 = 已解出题目的分值之和
排名     = 总分降序
```

## 轮次流程（最终）

```
没有定时器，没有轮次，没有兜底。
```

```
new   → 派一道题（需满足：当前无题，或当前题已 AC，或当前题已被放弃）
s     → 提交思路，判题
首个 AC → 当前题关闭，等人工发 new
g     → 放弃当前题，当前题关闭，等人工发 new
```

**为什么没有死锁**：没人 `new` 时游戏是暂停状态，不是故障状态。
当前题只有两种终态：被 AC，或被放弃。两者都能解锁 `new`。

## 群难度进度

`new` 派题时按群当前难度档 `D` 选题，`D` 初始 1200。
每派 20 道后评估一次：解出率 ≥30% 升一档，≤10% 降一档。

## 关键规则

| 项 | 规则 |
|---|---|
| 计分 | 只计**首次 AC**，重复解同一题不再得分 |
| WA | **不扣分**，只是没分 |
| 放弃 `g` | 无分，不扣分 |
| 每档上限 | 20 道（由「每档派 20 道」自然满足） |
| 排名并列 | 总分相同 → 解题数多者优先 → 首次通过率高者优先 |
| 中途加入 | 从加入后下一道题开始计分，旧题不可补做 |

## 为什么防刷

| 玩家 | 总分 |
|---|---|
| 新手（刷 100 道 800 分题） | 2,000 |
| 新手（认真做 30 道中级题） | 7,600 |

**刷简单题反而输 3.8 倍**：每档只派 20 道，刷满 800 档也只有 2000 分，
而认真做 30 道中级题就有 7600 分。

完整对照：

| 玩法 | 总分 | 占比 |
|---|---|---|
| 每档刷满 20 道 | 196,200 | 100% |
| 大佬（35 道全难题） | 90,000 | 45.9% |
| 高级（40 道） | 52,000 | 26.5% |
| 中级（50 道） | 21,900 | 11.2% |
| 新手（30 道中级） | 7,600 | 3.9% |
| 新手（刷 100 道 800） | 2,000 | 1.0% |

## 为什么废弃 ELO（保留推导，避免重蹈）

ELO 平衡条件 `p = 0.58`，而 `p` 只取决于「题目难度 − 玩家 rating」。

全群同一道题 → 所有人面对相同难度 → 所有人收敛到「题目难度 + 56 分」→ **无区分度**。

模拟（5 个不同真实水平玩家，10000 题后）：

| 真实水平 | 最终显示 |
|---|---|
| 1200 | 140（地板） |
| 1400 | 256（地板） |
| 1500 | 912（乱跳） |
| 1700 | 2903（天花板） |
| 2000 | 2969（天花板） |

两极分化，中间几乎无人。真实 CF 能区分，是因为**强手主动挑更难的题**；
选题权被拿走，判据就没了。

尝试过的补救及结果：

- **对称衰减惩罚** → 期望变化恒为 0，退化成随机游走
- **排名制 + 提交次数** → 多人同时一次 AC 时信号饱和，排序退化
- **排名制 + 时间决胜** → 排序正确，但仍在「全群同一道」下需要人少时退回 ELO，机制过于复杂

结论：**在「全群同一道题」的前提下，任何 rating 方案都不可靠。改用积分制。**
